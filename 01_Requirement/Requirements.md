#Requirement Document 

Signup Module
REQ-001 User can Signup using valid Credentials. 
REQ-002 Error message should get displayed for invalid credentials.

Login Module 
REQ-001 User can login using valid credentials given when signing up.
REQ-002 Error message should get displayed for invalid credentials. 
REQ-003 User can logout successfully. 

Dashboard Module 
REQ-001 Users can get a better UI and UX interface 
REQ-002 User can navigate the whole website easily

Product Module 
REQ-001 User can set the filter to select the product in a perticular price range.
REQ-002 User can set the filter to find a product from A-Z or Recently add products.
REQ-003 User can set the filter to find product from lowest to highest or highest to lowest. 
REQ-004 Product price should be diplayed in big font size for users convenience.

Cart Module 
REQ-001 User can add product to cart and can add in multiple quantity (nike bagpack x3).
REQ-002 User can delete product from the cart.
REQ-003 User should have a contiune shopping and proceed to payment feature in cart.
REQ-004 When user proceed to payments the payment message should be diplayed product is successfully buyed.
